# Linux System Basics

## Useful commands

- `whoami` - Current user
- `pwd` - Current directory
- `ls -lah` - List files
- `free -h` - Memory usage
- `df -h` - Disk usage
- `lsblk` - Disks and partitions
- `ip a` - Network interfaces
- `ip route` - Routing table
- `systemctl --failed` - Failed services
